# Evolucion Academica v2.0 - Sistemas

README / EXPLICACION DEL TRABAJO

1. COMO FUNCIONA EL PROGRAMA:
Este programa es una actualizacion de la tarea anterior para controlar las notas de los estudiantes, ahora, el sistema te pide el nombre, el carnet (CI) y la nota, para calcular el bono, el codigo agarra los ultimos dos numeros del carnet usando la funcion Substring, los convierte en un numero entero y le saca el 7% ese resultado se lo suma directamente a la nota original para sacar el promedio final y luego usa 
unos cuantos "if" y "else if" para revisar en que categoria se queda el estudiante si es Excelente, bueno, regular o si quedo Observado

2. COMO AYUDA LA EVOLUCION DE SOFTWARE SIN REESCRIBIR TODO DESDE CERO?
Nos ayuda mucho porque nos ahorra tiempo y evita que arruinemos lo que ya funcionaba, como en el laboratorio anterior ya teniamos listos los metodos para leer los numeros 
y validar que no se metan letras, en esta version solo tuvimos que concentrarnos en escribir la formula del bono del carnet y la nueva tabla de clasificaciones dentro del Main no hubo necesidad de borrar todo ni de volver a programar los controles desde el principio
